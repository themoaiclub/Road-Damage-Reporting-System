# Road-Damage-Reporting-System
City motorists and pedestrians facing dangerous potholes, broken street pavements, or missing manhole covers lack an easy online portal to report road hazards to municipal engineering departments. The proposed solution allow citizens to log geotagged road damage reports, view repair status, and track municipal road repairs. The project provides an interactive frontend solution that addresses this need without relying on backend services.
Core functional features:
• Pothole reporting form with Street Name, Landmark, Ward Number, Severity (Minor Crack, Deep Pothole, Open Manhole), and Photo upload placeholder
• Urgency priority badge highlighting deep road hazards on busy arterial roads in bold red
• Interactive city repair tracking table filtering complaints by Ward and Status (Reported, Inspected, Work in Progress, Repaired)
• Community confirmation button where neighbors can confirm when a pothole is successfully repaired
